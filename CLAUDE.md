# Portfolio project

Read README.md, ARCHITECTURE.md, and docs/REVAMP.md for current structure, evidence, and outstanding work. The app is Next.js 16.3 with React 19 and React Three Fiber. It lives in `sri_portfolio/sri_portfolio` to preserve the hosting root.

The environment is the website: one invented spherical world with connected biomes and a spatial feel. The `/story` route uses the same content in a conventional reading layout. Do not restore desktop/spatial modes or an environment embedded inside a portfolio card. Follow the rendered-review gate in `AGENTS.md` after every major change.

Use local fonts, semantic controls, responsive layouts, reduced-motion support, and on-demand rendering. Verify actual browser behavior and keep personal claims grounded in the user’s statements and public evidence.
