# Reading-page thumbnails

These WebP files are captures of the actual `/rooms/<id>` pages, not separately designed covers. BiomePages and Spotlight use the same images. They are decorative; the enclosing controls provide the accessible page name.

Captured October 2, 2026 from the local production build at 1080 × 800, with loaded fonts/images and settled entrance motion. The browser surface returns a 1065 × 789 capture at that viewport. Each image crop is x=0, y=68, width=1050, height=650 (content below the standalone toolbar, without the scrollbar). Converted to 720 × 446 WebP, quality 86. The ten images total approximately 212 kB. No live pages/iframes or duplicate animations run inside previews.

After changing a reading page's first screen, recapture its corresponding image using the browser screenshot tool and the same dimensions, then convert with sharp. Inspect the card next to the actual room, including phone and tablet layouts. Preserve the complete crop; do not restyle its text or substitute generated artwork. Update the capture date here when refreshing images.
