# sri.glb

This is a rigged and animated chibi Sri: warm brown skin, short dark wavy hair, a tee, dark trousers, white sneakers and a black watch on the left wrist.

## Source and licence

- All geometry is original work, generated by `scripts/blender/character/build.py` in Blender 5.2. The body is modelled as signed-distance shapes, meshed with OpenVDB and decimated. The hair is swept clump strands. The face features are shells fitted to the head. No third-party meshes are used.
- The eye, hair, mouth and skin maps are procedural and baked by the same script.
- The fabric weave normal is `public/materials/fabric-linen/normal.webp` (Poly Haven "rough_linen", CC0).
- The model therefore ships as the project's own work plus CC0 assets.

Rebuild: `blender -b --python scripts/blender/character/build.py -- --out public/models/characters/sri.glb`

The loader needs `MeshoptDecoder` (`gltfLoader.setMeshoptDecoder(MeshoptDecoder)` from `three/examples/jsm/libs/meshopt_decoder.module.js`). The file uses these extensions: KHR_materials_sheen, clearcoat, anisotropy, specular and texture_transform. `MeshPhysicalMaterial` supports all of them.

## Meshes and materials

All meshes are skinned to the one skeleton.

| Mesh | Materials |
|---|---|
| Body (head, neck, forearms, hands) | `skin` |
| Face | `eye`, `lash`, `brow`, `mouth`. Morph targets `blink` and `smile` (see below) |
| Hair | `hair` (strand normal map; V runs along each strand) |
| Shirt | `shirt` |
| Trousers | `trousers` |
| Shoes | `shoe_sole`, `shoe_upper`, `shoe_lace` |
| Watch | `watch` |

- To recolour the shirt, set `material.color` on `shirt`. Its base-colour texture is near-white and only holds baked occlusion and mottling, so `color` acts as the tint. The default is `#1c1c1f` (linear 0.0116).
- `trousers` and the shoe materials work the same way.
- In three.js the Face mesh loads as a Group with one Mesh per material. Each of those Meshes has its own `morphTargetDictionary` (`{blink: 0, smile: 1}`), so set `morphTargetInfluences` on every child.

## Skeleton

- Trunk: `hips` (root, carries the translation) → `spine` → `chest` → `neck` → `head`
- Arms: `chest` → `shoulder_{L,R}` → `upper_arm_{L,R}` → `lower_arm_{L,R}` → `hand_{L,R}`
  - `lower_arm_twist_{L,R}` is a child of `lower_arm`. It takes half the wrist roll so the forearm does not candy-wrap. The clips drive it already. If you pose `hand_*` procedurally, give the twist bone half of the hand's roll about the forearm.
  - Fingers are `{thumb,index,middle,ring,pinky}_{01,02,03}_{L,R}`.
- Legs: `hips` → `upper_leg_{L,R}` → `lower_leg_{L,R}` → `foot_{L,R}` → `toes_{L,R}`
- `L` is the character's left, which is +X in glTF.
- Every hinge bends about the bone's local X.

## Animations (30 fps, in place)

| Clip | Frames | Seconds | Loop | Notes |
|---|---|---|---|---|
| `idle` | 120 | 4.0 | yes | Breathing, weight shift, head drift, blink at 1.3 s |
| `walk` | 18 | 0.6 | yes | Authored for 1.2 m/s (stride 0.72 m per cycle). Feet stay planted during stance with a heel-toe roll. For another speed, set `action.timeScale = speed / 1.2` |
| `typing` | 120 | 4.0 | yes | Seated on a 0.50 m seat at a 0.78 m desk, finger taps, two blinks |
| `wave` | 66 | 2.2 | no (one-shot) | Right-hand wave with a smile morph. Starts and ends on the idle pose. Use `LoopOnce` and `clampWhenFinished = false`, then crossfade back to idle |
| `sit` | 150 | 5.0 | yes | Relaxed on a 0.46 m sofa, leaning back 9°, hands on thighs, feet swinging, blinks, light smile |

Every clip includes a `weights` track for the Face morphs. `walk` has no root motion, so move the object at 1.2 m/s × timeScale.

### Seated clips

In both seated clips the origin stays on the floor directly under the hip joints. Put the root at floor level beneath the seat, about 0.10 m behind the seat's front edge. The thighs run forward along +Z.

| | `typing` (0.50 m seat) | `sit` (0.46 m sofa) |
|---|---|---|
| Hip joint height | 0.566 | 0.526 |
| Knee | y 0.567, z +0.235 | y 0.525, z +0.237 |
| Ankle (feet dangle) | y 0.35, z +0.19 | y 0.32, z +0.17 |
| Wrists | (±0.093, 0.80, +0.235): 2 cm above a 0.78 desk top; keyboard centre about 0.30 m forward of the root | (±0.085, 0.60, +0.14) on the thighs |
| Shoulders | y 0.82, z +0.02 (leaning forward 7°) | y 0.78, z −0.04 (leaning back); sofa back should be about 0.15 m behind the root |
| Top of hair | 1.325 | 1.28 |

- The character is 1.29 m tall, so on a 0.50 m chair the feet hang about 0.27 m above the floor. Add a footrest or accept the dangle.
- The desk front edge should be at z ≤ +0.15 so the forearms clear it.
